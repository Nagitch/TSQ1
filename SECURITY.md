# Security Policy

## Supported versions

TSQ1 has not published a stable release. Security fixes are applied to the
latest `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/Nagitch/TSQ1/security/advisories/new)
to describe the affected code, impact, reproduction steps, and any suggested
mitigation.

You should receive an acknowledgement through the advisory within seven days.
After triage, maintainers will coordinate a fix and disclosure timeline there.
